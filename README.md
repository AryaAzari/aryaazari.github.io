## Projects

### 1. Percolation & Percolation Visualizer
A Java implementation of the **Percolation problem** from algorithms, with a visualizer that simulates how liquid percolates through a grid of open and blocked sites.  
- Built using **Union-Find (Weighted Quick Union)** to efficiently check connectivity.  
- Includes an interactive visualization for users to run and observe simulations.  

**How to run:**
```bash
# Compile
javac Percolation.java PercolationVisualizer.java WeightedQuickUnionUF.java

# Run the visualizer
java PercolationVisualizer <input-file.txt>
```
